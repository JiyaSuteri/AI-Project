Chapter 4 • Mathematical Rigor & Proof

Cost Formulation & Admissibility Proof

Mathematical guarantee that Saffron AI's $A^*$ search never returns a suboptimal table allocation.

$$\text{Cost}(t, p) = w_1 \cdot (\text{Cap}(t) - p.\text{size}) + w_2 \cdot \mathbb{I}_{[\text{Zone}(t) \neq p.\text{pref}]} + w_3 \cdot \mathbb{I}_{[p.\text{VIP} \land \neg \text{Quiet}(t)]}$$ $$\text{Heuristic Function: } h(n) = \max(0, \text{Cap}(n) - p.\text{size})$$

Theorem: Heuristic Admissibility & $A^*$ Global Optimality

Statement: An allocation heuristic $h(n)$ is admissible if $\forall n, \; 0 \le h(n) \le h^*(n)$, where $h^*(n)$ is the true optimal remaining cost.

Proof:

  1. Let $w_1 = 1.0$, and penalties $w_2, w_3 \ge 0$.
  2. For any valid candidate table $n$, the true minimal cost to seat the party is $h^*(n) = (\text{Cap}(n) - p.\text{size}) + \text{Penalties}$.
  3. Since $\text{Penalties} \ge 0$, it follows directly that: $h^*(n) \ge 1.0 \cdot (\text{Cap}(n) - p.\text{size}) = h(n)$.
  4. Because $h(n)$ never overestimates the true remaining cost, $h(n)$ is strictly admissible.
  5. Conclusion: By the optimality theorem of $A^*$ tree search (Russell & Norvig, Theorem 3.1), the first goal node popped from the priority queue is mathematically guaranteed to be the global optimum. █

Waiter Workload Objective Function

When Table $t$ is occupied, assign Waiter $w^* \in W$ minimizing:

$$w^* = \arg\min_{w \in W} \left( \alpha \cdot \text{ActiveTables}(w) + \beta \cdot \text{TotalGuests}(w) + \gamma \cdot \text{Dist}(w, t) \right)$$

Eliminates server overload and drops workload variance σ² from 4.62 to 0.88.

Chapter 9 • Viva Defense & Conclusion

Conclusion & Anticipated Viva Defense Q&A

Summary of contributions and ready answers for examination questions.

Q1: Why $A^*$ instead of Reinforcement Learning?

Answer: "Live restaurant allocation requires a deterministic, instantaneous decision with zero exploration risk. $A^*$ guarantees provable optimality without requiring millions of trial steps. For future work, we plan to use RL for predicting meal durations while keeping $A^*$ for allocation."

Q2: How do you guarantee the heuristic is admissible?

Answer: "Since our cost function penalizes capacity waste plus non-negative zone and VIP penalties ($w_2, w_3 \ge 0$), the true cost $h^*(n)$ is always $\ge (\text{Cap}(n) - \text{size})$. Because $h(n) = \max(0, \text{Cap}(n) - \text{size})$, $h(n) \le h^*(n)$ always holds, proving admissibility."

Q3: How does the system prevent double-seating?

Answer: "The 5-state Table FSM strictly blocks allocation to any table in RESERVED, OCCUPIED, DINING, or DIRTY states. SQLite transaction locks ensure atomic transitions so concurrent requests cannot seat the same table."

Q4: What happens if Groq API is offline?

Answer: "The system implements graceful degradation: the local TF-IDF retriever extracts the top-matched culinary cards and presents them directly in the UI even if the external LLM call fails."
